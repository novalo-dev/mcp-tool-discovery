# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and precise, assume good faith, criticise code rather than
people, and keep in mind that most contributors give their own time.

Harassment, insults or discrimination are not accepted, in any form and in any
place of the project: issues, pull requests, reviews, discussions.

Report a problem privately to the maintainer through
[novalo.fr](https://novalo.fr). Reports are read by the maintainer only and
answered within a week.
